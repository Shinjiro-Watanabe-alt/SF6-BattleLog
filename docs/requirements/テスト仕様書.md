# SF6-BattleLog テスト仕様書

## 1. テスト方針

### 1.1 構成

- **静的・ロジック確認**: JavaScript構文、入力制約、JSONデータ構造、IndexedDB移行を確認する。
- **統合・実機確認**: AndroidブラウザまたはPWAで、実際の入力、保存、再読込、取込、外部遷移を確認する。

### 1.2 外部サービスの扱い

- GitHub Pagesは手動公開後にページを確認する。
- YouTubeは限定公開URLを実際に開く確認のみ行う。動画の内容やアカウント情報はテストデータに含めない。

### 1.3 不安定な確認の扱い

通信・YouTube・GitHub Pagesの一時的な失敗は、まず再実行または再読込する。再現する場合は、URL、端末、操作、表示されたエラーを記録して原因を調査する。

## 2. 実行方法

```bash
node --check app.js
node --check sw.js
```

リポジトリ直下で実行する。ブラウザテストはGitHub Pages公開後にAndroid実機で行う。
